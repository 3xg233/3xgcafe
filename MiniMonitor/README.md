# MiniMonitor · 极简桌面悬浮性能监控器

半透明深蓝黑底悬浮小窗（壁纸透出可见），四角制表符角标，长条进度线，常驻桌面角落，一眼看清电脑状态。

## 运行

- 双击 `dist/MiniMonitor.exe` 即可（需 .NET 9 桌面运行时，本机已具备）。
- 若需显示 **CPU 温度**：部分主板/笔记本需要**右键 → 以管理员身份运行**，否则温度显示 `--`。

## 显示内容

七项指标纵向排列，每项 = 左侧标签 + 细直线进度线 + 右侧数值：

```
CPU  ████████░░░░░  12%
TMP  ████████░░░░░  68°
GPU0 ██░░░░░░░░░░░   5%
GPU1 █░░░░░░░░░░░░   3%
MEM  █████████████  71%
DSKC ██████████░░░  66%
DSKD ██████░░░░░░░  55%
```

| 指标 | 含义 | 刷新频率 |
|------|------|----------|
| CPU  | 处理器总占用率 | 1 秒 |
| TMP  | CPU/ACPI 热区温度（普通权限可读，无需管理员） | 5 秒 |
| GPU0 / GPU1 | 前两张显卡占用率（GPU Engine 计数器，取最大引擎，口径同任务管理器） | 2 秒 |
| MEM  | 物理内存使用率 | 1 秒 |
| DSKC / DSKD | C 盘 / D 盘使用率（盘不存在时显示 --） | 1 秒 |

| 指标 | 含义 | 刷新频率 |
|------|------|----------|
| CPU  | 处理器总占用率 | 1 秒 |
| MEM  | 物理内存使用率 | 1 秒 |
| DSK  | 所有硬盘总占用率 | 1 秒 |
| TMP  | CPU 温度（ACPI/热区，无权限时显示 --） | 5 秒 |

## 操作

- **左键按住拖动**：随意摆放位置（默认在屏幕右上角）
- **右键**：菜单
  - 窗口置顶（默认关闭，允许被其他窗口覆盖；需要时手动开启）
  - 开机自启（写入当前用户注册表 Run 项）
  - 复位到屏幕右上角
  - 退出
- **系统托盘**：图标双击可唤起窗口；右键同样提供置顶 / 开机自启 / 退出

## 数据与隐私

- 全部数据本地采集，不上传任何信息。
- 位置与设置保存在 `%APPDATA%\MiniMonitor\settings.json`。

## 常见问题

- **温度不显示**：非管理员权限时 ACPI 温度被拒绝访问，请以管理员身份运行；部分台式机主板未暴露热区接口，属正常情况。
- **悬浮窗挡住全屏内容**：右键取消勾选“窗口置顶”即可。

# MiniMonitor

极简桌面悬浮性能监控器，常驻桌面角落，一眼看清电脑状态。

## 简介

半透明深蓝黑底悬浮小窗，四角制表符角标，长条进度线。它不打扰你，只是安静地待在角落，实时显示 CPU、温度、显卡、内存与磁盘占用。

- 单文件、绿色免安装（便携版双击即用，无需安装任何运行时）
- 全部数据本地采集，**不上传任何信息**
- 体积小、常驻内存低

## 系统要求与获取

- 系统：**Windows 10 / 11（64 位）**
- 从 GitHub Releases 下载：https://github.com/3xg233/3xgcafe/releases
- 两种版本任选其一：
  - **便携版（推荐）**：下载 `MiniMonitor-portable-*.zip`，解压后双击 `MiniMonitor.exe` 即可，**无需安装 .NET 运行时**。
  - **框架依赖版**：下载 `MiniMonitor-*.zip`（或 `dist/MiniMonitor.exe`），需先在系统安装 **.NET 9 桌面运行时**（免费，从 dotnet.microsoft.com 获取）。

## 显示内容

悬浮窗纵向排列七项指标，每项 = 左侧标签 + 细直线进度条 + 右侧数值：

| 指标 | 含义 | 刷新频率 |
|------|------|----------|
| CPU  | 处理器总占用率 | 1 秒 |
| TMP  | CPU / ACPI 热区温度 | 5 秒 |
| GPU0 / GPU1 | 前两张显卡占用率（口径同任务管理器） | 2 秒 |
| MEM  | 物理内存使用率 | 1 秒 |
| DSKC / DSKD | C 盘 / D 盘使用率（盘不存在时显示 `--`） | 1 秒 |

## 使用

- **左键按住拖动**：随意摆放位置（默认在屏幕右上角）。
- **右键菜单**：
  - 窗口置顶（默认关闭，需要时手动开启）
  - 开机自启（写入当前用户自启项）
  - 复位到屏幕右上角
  - 退出
- **系统托盘**：图标双击唤起窗口；右键同样提供置顶 / 开机自启 / 退出。

> 显示 **CPU 温度** 需要更高权限：若温度显示 `--`，请右键 → 以管理员身份运行（部分台式机主板未暴露热区接口，显示 `--` 属正常现象）。

## 数据与隐私

- 全部数据本地采集，不上传任何信息。
- 设置（窗口位置 / 置顶 / 自启）保存在 `%APPDATA%\MiniMonitor\settings.json`。

## 常见问题

- **温度显示 `--`**：普通权限下 ACPI 温度被系统拒绝读取。请右键 → 以管理员身份运行；部分台式机主板未暴露热区接口，显示 `--` 属正常。
- **悬浮窗挡住全屏内容**：右键取消勾选"窗口置顶"即可。

# 3xgcafe Guard

> 3xgcafe 系列工具之一（原名 ScreenGuard）

Windows 桌面防偷窥工具：**你离开电脑一段时间后自动锁定屏幕，必须输入密码才能继续使用。**

适合"设置里已让屏幕常亮"的场景——屏幕不会自动关，但人一走开电脑仍处于敞开状态。3xgcafe Guard 补上这道门。

- 纯绿色单文件，双击即用，无需安装、无需 .NET 运行时
- 常驻托盘，占用极低；有操作时不打扰，无操作时倒计时
- 仅锁定操作，**不关机、不休眠、不影响后台运行的程序**（下载、渲染、编译照常进行）

## 快速开始

1. 双击 `3xgcafe-Guard.exe` 运行。
2. 首次启动会要求**设置解锁密码**（至少 4 位，可含字母/数字/符号）和无操作多久后锁定。
3. 之后它静静待在托盘里。你离开超过设定时间，屏幕就会被全屏锁定界面覆盖，必须输入密码解锁。

## 日常使用

**锁定发生时**

- 整个桌面（含多显示器）被锁定界面覆盖，键盘鼠标被封锁，无法操作锁屏界面背后的任何程序。
- **锁屏背景为实时模糊（毛玻璃）**：透过锁屏界面可以看到后方各程序窗口的**大致轮廓与运行状态**（页面在动、视频在播都能实时看到），但经过系统级强模糊 + 深色压暗，文字、文件名、聊天内容等细节已完全不可辨认，兼顾观感与隐私。
- 输入密码 → 回车（或点"解锁"）即可恢复；点输入框右侧的**"显示"**按钮可明文查看已输入内容（再点"隐藏"切回）。
- 连续输错 3 次开始有等待冷却，且等待时间随错误次数递增（最长 60 秒）。

**桌面悬浮按钮**

启动后桌面上会出现一个黄色胶囊按钮（默认在屏幕右下角），与 WallpaperPure 同款尺寸：

- **左键单击** = 立即锁定（起身离开时一点就走）
- **右键** = 弹出功能菜单（临时关闭监控、设置、退出等），不用再去翻托盘
- **按住拖动** = 移动到任意位置（自动记住，下次启动恢复）
- 按钮不置顶：被打开的窗口会正常盖住它，不打扰日常使用

**托盘图标（右键菜单）**

| 菜单项 | 作用 |
|---|---|
| 立即锁定 | 不用等倒计时，马上锁屏（起身接水、离开工位时好用） |
| 临时关闭监控 | 15 分钟 / 30 分钟 / 1 小时 / 2 小时；到点**自动恢复**监控。看视频、演示时用 |
| 恢复监控 | 提前手动恢复 |
| 设置... | 改锁定时间、改密码、改提示语 |
| 开机自启 | 勾选后开机自动运行 |
| 退出 | 完全退出程序 |

鼠标悬停托盘图标可看到倒计时状态（如"保护中，3 分 12 秒 后锁定"）。

## 设置说明

| 项目 | 说明 |
|---|---|
| 锁定时间 | 无键鼠操作达到该时长即锁定，1–180 分钟 |
| 锁屏背景模糊 | 默认开启：背景为 DWM 实时模糊（可看到后方程序大致运行状态）。关闭后使用纯深色背景 |
| 解锁密码 | 修改密码需先输入旧密码；两个密码框留空表示不修改 |
| 锁定期间阻止屏幕关闭 | 默认关闭。开启后锁定时会阻止显示器休眠/关闭（适合需要一直看到锁屏界面的场景） |
| 锁屏提示语 | 显示在密码框上方，可留一句话（如"请勿使用，请联系 xxx"） |
| 开机自启 | 写入注册表 `HKCU\...\Run\3xgcafe-Guard` |

配置文件位置：`%APPDATA%\3xgcafe\Guard\settings.json`（密码为 PBKDF2 加盐哈希，不存明文）。

## 安全边界（请务必了解）

- **能挡住什么**：普通人坐到你的电脑前，无法操作任何程序、无法切窗口、无法关闭锁定界面，只能看到锁屏界面。
- **挡不住什么**：`Ctrl + Alt + Del` 是 Windows 的安全注意序列，由系统内核处理，**任何用户态程序都无法拦截**（这是 Windows 的设计，否则病毒就能彻底劫持你的电脑）。懂行的人可以按 `Ctrl+Alt+Del` 打开任务管理器结束本进程。
  - 对"防同事/家人随手用你电脑"这个场景足够；对"防专业攻击者"不够。
- **忘记密码怎么办**：`Ctrl+Alt+Del` → 任务管理器 → 结束 `3xgcafe-Guard.exe`，然后删除 `%APPDATA%\3xgcafe\Guard\settings.json`（或只删文件里的 PasswordHash / PasswordSalt 两行），重新启动即可重新设置密码。
- **不会做的事**：不联网、不上传任何数据、不记录你的输入内容（密码只在本地做哈希比对）。

## 常见问题

**第一次运行被 Windows 拦截？**
未签名的自制程序会被 SmartScreen / 智能应用控制提示。点"更多信息 → 仍要运行"，或先右键 exe → 属性 → 勾选"解除锁定"。

**看视频时被锁了？**
右键托盘图标 → 临时关闭监控 → 选一个时长（到点自动恢复）。

**锁定后画面全黑？**
锁定界面是深色的全屏遮罩，这是正常的。输入密码即可恢复，屏幕上会显示当前时间。

**多显示器怎么处理？**
锁定界面覆盖全部显示器，密码框显示在主显示器中央。

关于 · 音频提取工具
3xgVCPhelper 工具系列 · V1.0 Developer Beta

这是一款纯前端的视频音频提取工具，与「歌词写作工具」同属 VCPhelper 系列。所有处理都在你的浏览器本地完成，视频文件不会上传到任何服务器，隐私安全。

  • MP3：通用兼容性最好，有损压缩，体积小
  • WAV：无损原始音质，体积较大，适合后期剪辑
  • M4A (AAC)：苹果/移动端友好，压缩效率高
  • 原样提取：直接抽取音轨（如 AAC），零重新编码、速度最快
技术说明：本工具通过 ffmpeg.wasm 在浏览器内运行完整的 FFmpeg。 首次使用需联网下载约 32MB 的核心文件（自动在 npmmirror / jsDelivr / unpkg 多个 CDN 间切换，国内网络亦可访问），之后由浏览器缓存，重复使用无需再下载。 若直接双击打开本文件（file://）出现异常，请用本地 HTTP 服务器或将其部署到网站后访问。

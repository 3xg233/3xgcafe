# 音频提取工具（3xgVCPhelper）

一款**纯前端**的视频音频提取工具。整个程序就是一个 HTML 文件，用浏览器打开即可使用，**无需安装、无需后端服务器**。

## 测试版 `audiobeta.html`（V1.0 Developer Beta）

- 拖拽或点击选择视频文件，自动读取文件名、大小、时长、分辨率。
- 输出格式四选一：
  - **MP3**（可选 128 / 192 / 320 kbps，通用兼容性最好）
  - **WAV**（无损原始音质，体积较大，适合后期剪辑）
  - **M4A / AAC**（苹果与移动端友好，压缩效率高）
  - **原样提取**（直接抽取视频中的音轨，零重新编码、速度最快、音质无损）
- 处理全部在浏览器内通过 [ffmpeg.wasm](https://ffmpegwasm.netlify.app/) 完成，**视频文件不会上传到任何服务器**。

## 运行方式
1. 推荐部署到任意静态网站托管服务，通过网址访问（示例：<https://3xgvcphelper.rth1.xyz/audiobeta.html>）。
2. 也可直接用浏览器打开 HTML 文件；若出现脚本加载异常，请改用本地 HTTP 服务器。

## 首次使用须知
- **首次提取需联网**：会从公共 CDN（npmmirror / jsDelivr / unpkg 依序自动降级）下载约 32MB 的 FFmpeg 核心文件，进度条实时可见；之后由浏览器缓存，重复使用无需再下载。
- 受 WebAssembly 单线程性能限制，大文件提取耗时较长，请耐心等待。

## 浏览器兼容性
- 需要支持现代 Web 标准（ES6+、WebAssembly、Cache API、Web Workers）的浏览器（推荐 Chrome / Edge / Firefox / Safari 近年版本）。

## 数据与隐私
- 视频与音频全程仅在本机浏览器内存中处理，**不上传任何数据**；FFmpeg 核心文件下载自公共 CDN，除此之外无任何网络请求。

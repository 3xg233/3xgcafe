# 歌词写作工具（3xgVCPhelper）

一款面向音乐人的**纯前端**作词辅助工具。整个程序就是一个 HTML 文件，双击即可在浏览器中运行，**无需安装、无需后端服务器**（单人模式）。

## 两个版本

### 稳定版 `lyrics.html`
- **完全离线**：不依赖任何外部资源，断网也能正常使用。
- 直接用浏览器打开即可。
- 你的歌词草稿与设置保存在浏览器的 `localStorage` 中；更换浏览器或清除缓存会丢失，重要稿件请自行复制备份。

### 测试版 `lyricsbeta.html`（V1.2 Developer Beta）
- 在稳定版的基础上增加了**多人实时协作**功能。
- 单人作词模式同样可离线使用。
- **实时协作需要联网**：页面会通过 CDN 动态加载 [PeerJS](https://peerjs.com/) 库，并连接 PeerJS 官方公共信令服务器（`0.peerjs.com` 云）来撮合连接。
  - 因此协作功能依赖第三方公共服务，不在你的掌控范围内；若该服务不可用，协作会失败，但**单人编辑不受影响**。
- 协作方式：创建或加入一个房间（Room），通过房间号 / Peer ID 邀请他人加入，多方实时同步编辑内容。

## 如何运行
1. 直接用浏览器打开对应的 HTML 文件（推荐 Chrome / Edge 等现代浏览器）。
2. 或把文件放到任意静态网站托管服务（GitHub Pages、Nginx、对象存储等），通过网址访问。
3. 无需构建、无需安装依赖、无需数据库。

## 浏览器兼容性
- 需要支持现代 Web 标准（ES6+、localStorage、WebRTC）的浏览器。
- 协作功能需要浏览器支持 WebRTC（主流桌面浏览器均支持）。

## 数据与隐私
- **单人数据**：仅存储在你本机浏览器的 `localStorage` 中，不会上传到任何服务器。
- **协作数据**：通过 WebRTC 在点对点（P2P）参与者之间直连传输；PeerJS 信令服务器仅负责连接撮合，**不中转**协作内容。

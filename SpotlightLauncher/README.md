# SpotlightLauncher

按下快捷键即呼出的聚焦式应用启动器，并附带剪贴板历史功能。

界面复刻《终末地》游戏语言：黑灰底 + 荧光黄绿点缀 + 工业终端标题栏，半透明圆角面板随结果数量自适应高度。

## 简介

- 全局热键一键唤起，输入即搜，回车即开。
- **应用查找**：支持中文名、拼音首字母、英文包名。
- **剪贴板历史**（v1.2 新增）：自动记录复制过的文本与图片，随时回溯、模糊搜索、一键复制回剪贴板。
- 单文件、绿色免安装（便携版双击即用）。
- 全部数据本地存储，**不上传任何信息**。

## 系统要求与获取

- 系统：**Windows 10（版本 19041 及以上）/ 11（64 位）**
- 从 GitHub Releases 下载：https://github.com/3xg233/3xgcafe/releases
- 两种版本任选其一：
  - **便携版（推荐）**：下载 `SpotlightLauncher-portable-*.zip`，解压后双击 `SpotlightLauncher.exe` 即可，**无需安装 .NET 运行时**。
  - **框架依赖版**：下载 `SpotlightLauncher-*.zip`（或 `dist/SpotlightLauncher.exe`），需先在系统安装 **.NET 9 桌面运行时**（免费，从 dotnet.microsoft.com 获取）。

## 快速开始

1. 启动后程序驻留系统托盘。
2. 按 **`Ctrl + Alt + Space`** 唤起搜索框（也可双击托盘图标打开）。
3. 输入应用名，`↑` / `↓` 选择，`Enter` 启动，`Esc` 或点击窗口外部关闭。

## 应用查找

- 输入即过滤，支持：
  - 名称子串：`chrome` → Chrome、`微信` → 微信
  - 拼音首字母：`wx` → 微信、`jsq` → 计算器
  - 英文包名：`calc` → 计算器（UWP 应用按包名可搜）
- 索引范围：开始菜单、UWP / 商店应用、桌面快捷方式、已安装程序（Program Files）、Steam 游戏库、Epic 游戏。
- 常用应用会凭使用频率自动排在前面。

## 剪贴板历史

- 唤起后默认是「应用查找」模式；按下 **`Alt`** 在两种模式间切换（标题栏标签页指示当前模式）。
- **不输入关键词**：按时间倒序展示全部复制记录。
- **输入关键词**：模糊匹配你复制过的文本（支持部分文本与一定程度的模糊识别）。
- 图片以缩略图展示；文本记录可显示预览与字符数。
- 在结果上 `Enter` 或单击，可将该条目**复制回系统剪贴板**；右键菜单可打开文件所在位置、复制路径等。
- 剪贴板记录保存在本地（`%APPDATA%\SpotlightLauncher\clipboard\`），不上传。

## 托盘菜单

- 双击托盘图标打开启动器。
- 右键菜单包含「开机自启」「退出」等。

## 常见问题

- **热键没反应**：`Ctrl + Alt + Space` 可能已被其他程序占用。此时托盘会弹提示，可双击托盘图标打开；或释放该快捷键后重试。
- **搜不到某些应用**：少数 UWP 应用未暴露入口，或应用未安装到当前用户，属正常现象。
- **刚启动搜索为空**：索引在后台构建（约 1 秒），稍候自动就绪。

# WallpaperPure — 一键隐藏桌面图标

一个极简的 Windows 桌面小工具：屏幕上放一个小胶囊按钮，点一下隐藏/显示桌面所有图标，方便纯净地观赏壁纸。

## 用法

- **双击运行** `WallpaperPure.exe`，屏幕右下角会出现一个圆角胶囊按钮（初次运行后可通过拖动摆放）。
- **灰色按钮** = 桌面图标正在显示；**荧光黄色按钮** = 桌面图标已隐藏（切换带 150ms 淡入淡出过渡）。
- **原地单击**按钮 = 切换图标显隐。
- **按住左键拖动** = 把按钮移动到任意你喜欢的位置（位置会自动记住，下次启动恢复）。
- **右键按钮** → 菜单：勾选 **开机自启**（随系统启动，注册表项指向当前运行的 exe），或 **退出**。

图标隐藏状态在重启电脑 / 重启资源管理器后依然保持；兼容 Wallpaper Engine 等壁纸软件。

按钮不会置顶悬浮：打开其他窗口时按钮会被正常盖住，不干扰日常使用。

## 系统要求

- Windows 10/11 x64
- 框架依赖版需要 [.NET 9 桌面运行时](https://dotnet.microsoft.com/download/dotnet/9.0)
- 绿色便携版无需安装运行时

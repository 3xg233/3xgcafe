# SpotlightLauncher · 终末地风格应用启动器

按下 `Ctrl + Alt + Space` 唤起居中的搜索框，输入应用名（支持拼音首字母）回车即启动。
界面复刻《终末地》游戏 UI 语言：黑灰底 + 荧光黄绿点缀（RGB 250,252,82）+ 密集地形等高线 + 白色卡片式搜索框 + 工业终端标题栏。

## 运行

- 双击/启动 `dist/SpotlightLauncher.exe`（需 .NET 9 桌面运行时，本机已具备）。
- 版本 v1.2 起支持窗口拖动与手动添加扫描路径。
- 版本 v1.3 起支持拖拽豁免、"失活时保持窗口"开关与热键开关。
- 版本 v1.4 起使用终末地风格应用图标(exe/任务栏/托盘统一)。
- 启动后驻留系统托盘，按 **Ctrl+Alt+Space** 唤起（可在托盘右键菜单退出）。
- 托盘图标双击也可打开启动器。

## 功能

- **搜索**：输入即过滤，支持
  - 名称子串：`chrome` → Chrome、`微信` → 微信
  - 拼音首字母：`wx` → 微信、`jsq` → 计算器
  - 英文包名：`calc` → 计算器（UWP 应用按包名可搜）
- **索引范围**：开始菜单快捷方式 + UWP/商店应用，约 120+ 条（本机实测）
- **启动**：普通应用直接拉起；UWP 应用通过 `shell:AppsFolder` 激活
- **键盘操作**：`↑`/`↓` 选择，`Enter` 启动，`Esc` 或点击窗口外部关闭
- **使用频率记忆**：常用应用自动排在前面（存于 `%APPDATA%\SpotlightLauncher\freq.json`）
- **界面**：半透明圆角面板，延续黑白极简风格，窗口随结果数量自适应高度
- **窗口拖动**：按住顶部标题行可拖动窗口，位置自动记忆（重启后恢复，屏外自动回退）
- **手动添加路径**：搜索框旁"+ 路径"打开管理对话框（添加 exe/文件夹、删除），或直接把 exe/文件夹拖到窗口上；增删后自动重建索引
- **拖拽友好**:从资源管理器拖文件期间窗口不自动隐藏,落下后自动回到前台
- **保持窗口开关**:托盘菜单勾选"失活时保持窗口"后点击外部不再收起;全局热键变为开关(窗口可见按一下收起,再按呼出)

## 调试参数（可选）

- `--no-autohide`：失活时窗口不自动隐藏（自动化测试用，一般用户不需要）

## 常见问题

- **热键冲突**：若 Ctrl+Alt+Space 被其他程序占用，托盘图标会弹提示，可双击托盘图标打开启动器。
- **搜索不到某些应用**：少数 UWP 应用未暴露 AppListEntry，或应用未安装到当前用户，属正常。
- **索引为空的瞬间**：启动后索引在后台构建（约 1 秒），期间搜索可能为空，稍后自动就绪。

## 技术栈

WPF + .NET 9，单文件发布；应用枚举用 WScript.Shell COM 解析快捷方式 + WinRT `PackageManager` 枚举 UWP；全局热键用 Win32 `RegisterHotKey`；拼音用 PinYinConverterCore。

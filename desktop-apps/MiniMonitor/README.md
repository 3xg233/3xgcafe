# 3xgcafe Monitor · 极简桌面悬浮性能监控器

> 3xgcafe 系列工具之一（原名 MiniMonitor）

半透明深蓝黑底悬浮小窗（壁纸透出可见），四角制表符角标，长条进度线，常驻桌面角落，一眼看清电脑状态。

## 运行

- 双击 `3xgcafe-Monitor.exe` 即可。发布版为自包含单文件（约 126MB），**无需安装 .NET 运行时**。
- 温度数据源优先用普通权限可读的热区计数器；读不到时再尝试需管理员权限的 MSAcpi。两者都不可用则显示 `--`（部分台式机主板未暴露热区接口，属正常情况）。

## 显示内容

十项指标纵向排列，每项 = 左侧标签 + 细直线进度线 + 右侧数值：

```
CPU  ████████░░░░░  12%
TMP  ████████░░░░░  68°
GPU0 ██░░░░░░░░░░░   5%
GPU1 █░░░░░░░░░░░░   3%
MEM  █████████████  71%
DSKC ██████████░░░  66%
DSKD ██████░░░░░░░  55%
BAT  ████████░░░░░  81%
RX   ███░░░░░░░░░░  4.5M
TX   █░░░░░░░░░░░░  312K
```

| 指标 | 含义 | 刷新频率 |
|------|------|----------|
| CPU  | 处理器总占用率 | 1 秒 |
| TMP  | ACPI 热区（主板区域）温度，**非 CPU 核心温度** | 5 秒 |
| GPU0 / GPU1 | 显卡占用率（GPU0/GPU1 固定对应系统适配器 0/1，顺序稳定；**悬停标签可见显卡名称**；GPU Engine 计数器，取最大引擎，口径同任务管理器） | 2 秒 |
| MEM  | 物理内存使用率 | 1 秒 |
| DSKC / DSKD | 磁盘使用率（默认自动检测前两个固定盘并按盘符显示标签，如 DSKC/DSKD；盘不存在时显示 --） | 1 秒 |
| BAT  | 电池电量（充电时显示 `87%+`；台式机/无电池显示 --） | 5 秒 |
| RX / TX | 物理网卡（有线/无线）下载 / 上传速率，自适应 B/K/M；进度条按 100Mbps 满格 | 1 秒 |

## 操作

- **左键按住拖动**：随意摆放位置（默认在屏幕右上角；点击穿透开启时不可拖动）
- **全局热键 `Ctrl+Alt+M`**：显示 / 隐藏窗口（热键被其他程序占用时静默失效）
- **右键**：菜单
  - 窗口置顶（默认关闭，允许被其他窗口覆盖；需要时手动开启）
  - 开机自启（写入当前用户注册表 Run 项）
  - 点击穿透（开启后鼠标事件穿透窗口，窗口不能拖动/右键，只能从托盘菜单关闭）
  - 显示指标（10 项指标可独立勾选显示/隐藏，至少保留 1 项，窗口高度自适应）
  - 窗口透明度（100% / 85% / 70% / 55% / 40% 五档，记住选择）
  - 复位到屏幕右上角
  - 隐藏窗口（隐藏后驻留托盘，监控不中断）
  - 退出
- **系统托盘**：图标双击可唤起窗口；右键提供 显示/隐藏窗口 / 置顶 / 开机自启 / 点击穿透 / 窗口透明度 / 复位 / 退出
- **多屏注意**：窗口位置按显示器交集校验，拔掉外接屏后窗口若在屏外会自动复位到右上角

## 数据与隐私

- 全部数据本地采集，不上传任何信息。
- 位置与设置保存在 `%APPDATA%\3xgcafe\Monitor\settings.json`。
- 磁盘行默认自动检测前两个固定盘；如需指定，在 settings.json 加 `"Drives": ["C","E"]`（1~2 个盘符字母，重启生效）。

## 常见问题

- **温度显示 `--`**：两种数据源（热区计数器 / MSAcpi）都不可用时的正常表现，见“运行”一节；TMP 为主板区域温度，不是 CPU 核心温度。
- **悬浮窗挡住全屏内容**：右键取消勾选“窗口置顶”即可。

## 自行编译

- 需要 **.NET 9 SDK**（仅编译用；发布的 exe 自包含，运行机器无需装运行时）。
- 发布命令：`dotnet publish -c Release -r win-x64 --self-contained true -o dist-portable`
- csproj 已内置 `IncludeNativeLibrariesForSelfExtract=true`：把 WPF 原生库（wpfgfx_cor3 等）打进单文件 exe（首次运行自解压到 `%TEMP%\.net\MiniMonitor`）。缺少该设置时，单独拷走的 exe 会因缺 DLL 闪退。
